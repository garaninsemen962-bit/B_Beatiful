# Проверка версии 2

Выполнено в Linux, Python 3.12.

Полный набор: 21 тест, 20 успешно, 1 пропущен (реальное выполнение Docker). Отдельно после фиксации image ID повторены 8 тестов платформы — успешно. Синтаксис Python и JavaScript проверен.

Покрытие:

- сравнение массивов, составные/вложенные ключи, типы скаляров, NULL, отсутствие атрибута, бакеты;
- роли, личный/поимённый/общий доступ, скачивание, отзыв прав;
- регистрация, административное подтверждение и блокировка, отзыв сессий, CSRF;
- реальная HTTP-загрузка ZIP и Python-файлов, извлечение русского docstring без исполнения;
- версии, конфликт одновременных изменений, запрет изменения истории;
- неизменность манифеста выполнения после правки прогона;
- серверные страницы, отчёты, сводная, заявки и HTML-экспорт;
- полный расчёт открытого датасета доверенными процедурами в тестовой фикстуре: 2002 заявки, 289533 строки сравнения, 502 заявки с различиями, 385 смен решений;
- Docker-команда с ограничениями и отказ без доступного контейнерного исполнителя.

Ограничения проверки:

- Docker daemon в этой среде отсутствует. Реальный контейнерный интеграционный тест приложен и включается DD_TEST_DOCKER=1 после сборки образа.
- Браузерная визуальная проверка не проводилась. HTTP-страницы и формы проверены автоматическими запросами, JavaScript — на синтаксис.
- Windows/Docker Desktop в этой среде не проверялись.
- Закрытый эталон организаторов не использовался.

Добавлена консольная команда сброса пароля. Повторно прошли 9 тестов платформы, включая смену пароля, отзыв сессий, сохранение ресурсов и отказ при неверном логине/коротком пароле.


Исправление редактора: полный набор Python — 24 теста, 23 успешно и 1 Docker-тест пропущен. Новые HTTP-регрессии проверяют сохранение кода/метаданных после отсутствия run и синтаксической ошибки, конфликт версий без потери буфера, извлечение docstring без run. `node tests/test_editor.js` проверяет Tab/Shift+Tab, отступы выделенных строк, Enter, многострочные строки Python, экранирование HTML и сохранение исходного текста после подсветки. JavaScript синтаксически проверен. Настоящий браузер для визуальной проверки в среде отсутствует.
