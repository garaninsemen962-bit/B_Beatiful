# Изменения 7 ноября 2026

Повторно сверены описание задачи, контракт витрины и материалы участников из исходного архива. Закрытый эталон организаторов не использовался.

Реализовано:

- точная сводная уникальных заявок: перенос полей, строки/столбцы, точные фильтры, личные макеты;
- локальный WebDataRocks 1.4.23 с русской локализацией для анализа наблюдений атрибутов;
- переход из ячейки к заявкам и выбранному атрибуту с сохранением среза, фильтров и обратного пути;
- исходные значения выбранного атрибута, включая различие типов и отсутствия;
- новые проверки в отдельном контейнерном выполнении по копии готовой витрины;
- асинхронный Gemini с предварительным просмотром сводки, историей, структурированным ответом и проверкой ссылок на доказательства;
- включение ответа Gemini в отчёт проверок и HTML-экспорт;
- ссылки журнала на выполненную версию кода и текущий скрипт;
- настройка абсолютных ссылок HTML через DD_PUBLIC_URL;
- импорт папок BEFORE/AFTER наряду с BEFORE_MASTER/AFTER_BETA;
- раздельные измерения этапов и воспроизводимый benchmark.

При перечитывании задания учтено: агрегаты counts и уникальные заявки по нескольким атрибутам неаддитивны; бизнес-специфические правила остаются в сменных Python-процедурах; изменения бакетов не подменяют сравнение исходных значений. Выполнение пользовательского Python на веб-хосте не добавлено.

Порядок обновления и настройки Gemini — в README. После замены кода необходимо пересобрать Docker runner. Реальный Docker и внешний Gemini API в среде разработки не проверены; браузер и HTTP-контракт Gemini проверены отдельно.

## Дополнение: диагностика RemoteDisconnected

Gemini-клиент вынесен в gemini_client.py. По умолчанию используется потоковый SSE с low thinking для Gemini 3; собирается только полный валидный JSON. Ошибки разделены по фазам, добавлены безопасные серверные логи и команда `python3 gemini_client.py --check`. Автоповтора нет. Это исправление недостатков клиента, а не подтверждённое устранение конкретного обрыва на пользовательском подключении. Для обновления нужны два файла: ai_review.py и gemini_client.py; Docker runner для этого дополнения не пересобирается.

## Дополнение: интерактивная страница и подробный анализ

Добавлены ai_models.py, ai_views.py и web/ai.js. Запуск и ожидание обновляют ответ/историю, без перезагрузки документа; форма и раскрытые данные сохраняются. Модель выбирается для отдельного анализа, каталог Google загружается по кнопке сервером с кешем и проверкой прав. Сводка расширена продуктовыми группами и пересечениями со сменой решений, ответ — цифрами, интерпретацией, альтернативами и планом проверки. Лимит ответа 14000 токенов, сводки 75 КБ. Новая версия промпта не перезаписывает старые ответы. Обновление этой версии выполняется заменой файлов проекта с сохранением state, по актуальному README.
